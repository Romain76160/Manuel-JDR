# Handouts joueurs — Manuel I : L'Héritage du Wuju

Ce dossier contient uniquement des documents pouvant être montrés aux joueurs sans révéler d'informations réservées au MJ.

## Ordre d'utilisation

1. `05-regles-du-temple-wuju.md` — après l'accueil officiel au Temple Wuju.
2. `04-vision-statue-sans-visage.md` — après la vision commune avant le départ aux Chutes.
3. `02-trois-postures-wuju.md` — au Bassin du Silence.
4. `01-poeme-urong.md` — devant l'épée de Maître Urong.
5. `03-aide-techniques-wuju.md` — dès que les PJ commencent à recevoir les enseignements Wuju.
6. `06-cartes-objets-doran.md` — après l'assaut du temple, si Yi remet les récompenses.

## Principe éditorial

Un handout doit apporter une information que les joueurs ont intérêt à garder sous les yeux : texte rituel, règle acquise, vision ou objet.

Les informations sur Xolaani, Kayn, les PCW, les conditions de victoire et les secrets du Temple Wuju restent dans le manuel du MJ.
