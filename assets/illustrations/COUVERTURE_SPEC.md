# Couverture finale — Manuel I : L'Héritage du Wuju

> **Statut : spécification canonique de production.**

## Rôle

La couverture doit annoncer d'abord **Ionia et le Wuju**.

La menace Darkin doit être perceptible, mais ne doit pas prendre le dessus ni révéler directement Xolaani.

## Composition

- illustration verticale de couverture ;
- vallée ionienne monumentale au lever ou au coucher du jour ;
- montagne centrale abritant le Temple Wuju ;
- une petite partie de l'entrée du sanctuaire visible dans la roche ;
- cascades, brume, pins, érables et végétation ionienne ;
- architecture Wuju élégante et intégrée à la montagne ;
- sentiment de calme ancien et de puissance contenue.

## Temple Wuju

Le Temple doit être compris comme **creusé dans la montagne**, pas comme un grand monastère extérieur.

Acceptable :

- porte monumentale ;
- quelques terrasses ou pavillons près de l'entrée ;
- ouvertures dans la falaise ;
- lumière chaude venant de galeries intérieures.

À éviter :

- immense ville-temple extérieure ;
- cinq étages visibles ;
- coupe architecturale ;
- battlemap.

## Menace Darkin

Très discrète.

Possibilités :

- fine lueur rouge dans une fissure lointaine ;
- nuages légèrement rouge sombre ;
- ombre anormale au pied d'une falaise ;
- deux courbes rouges presque imperceptibles rappelant des lames.

Ne pas montrer :

- Kayn en gros plan ;
- Rhaast dominant l'image ;
- Xolaani ;
- armée du Clan des Ombres ;
- cœur Darkin géant.

## Personnages

Aucun personnage n'est obligatoire.

Si une silhouette existe, elle doit être petite face au paysage, éventuellement un maître Wuju ou des voyageurs sur un sentier.

Le lieu doit dominer.

## Palette

Dominante :

- jade ;
- vert doux ;
- bleu brume ;
- pierre claire ;
- lumière dorée.

Accent :

- rouge sombre extrêmement limité.

## Texte

**Aucun texte intégré dans l'image générée.**

Le titre sera ajouté par Homebrewery :

- LA SECONDE GUERRE DARKIN
- Prologue
- L'Héritage du Wuju
- Une campagne dans l'univers de Runeterra
- Personnages de niveau 1 à 3

## Format

- portrait ;
- suffisamment d'espace calme dans le tiers supérieur pour le titre ;
- zone basse lisible pour un éventuel sous-titre ;
- détails conservant leur lisibilité à l'impression A4.

## Rejet automatique

Rejeter si :

- le Temple est principalement extérieur ;
- Kayn / Rhaast occupent le centre ;
- une corruption rouge envahit l'image ;
- l'image ressemble à une carte tactique ;
- du texte ou de faux caractères apparaissent ;
- l'image révèle directement Xolaani.
