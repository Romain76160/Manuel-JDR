# 2. Hiérarchie visuelle du livre

La progression graphique doit raconter la même histoire que le scénario.

## Début — le Wuju domine

Le lecteur doit d'abord voir :

- Ionia ;
- le monastère ;
- Maître Yi ;
- Jun et les autres disciples ;
- les couleurs jade, blanc, vert, bleu et pierre claire.

Kayn et les Darkin ne doivent pas encore envahir visuellement le livre.

## Milieu — la spiritualité devient inquiétante

Aux Chutes de Brume :

- plus de brume ;
- davantage de bleu et de turquoise ;
- ruines anciennes ;
- Royaume Spirituel ;
- premières touches de rouge sombre ou noir autour des Seigneurs des Darkin.

Jun devient plus importante visuellement.

## Fin — rupture Darkin

Pendant l'Assaut du Temple :

- nuit ;
- lanternes qui s'éteignent ;
- pierre sombre ;
- ombres ;
- rouge / noir / violet comme accents ;
- Kayn et Rhaast deviennent dominants.

Xolaani n'obtient sa vraie présence visuelle qu'en fin de Prologue ou dans les annexes.

# 3. Formats recommandés

## Pleine page

À réserver à :

- couverture ;
- ouverture de chapitre ;
- grande carte ;
- illustration majeure de fin.

Éviter plus d'une pleine page illustrée toutes les 4 à 6 pages de contenu.

## Demi-page / panoramique

À utiliser pour :

- paysages ;
- Chutes de Brume ;
- Temple Wuju ;
- transitions de scène.

## Portrait

À utiliser pour :

- Jun ;
- Ting ;
- Disciple de Doran ;
- Rhaast si on trouve un visuel cadré correctement.

## Petite vignette

À utiliser pour :

- annexes ;
- objets ;
- crédits ;
- techniques Wuju.

---

# 4. Recadrages recommandés

## Master Yi

Préserver :

- visage / masque ;
- arme ;
- posture ;
- suffisamment de décor pour rappeler Ionia.

Éviter un recadrage trop serré qui transformerait l'ouverture en simple portrait de champion.

## Jun

Préserver :

- visage ;
- arme / posture ;
- lecture claire de son statut de disciple.

Pour le chapitre II, préférer une composition laissant de l'espace autour d'elle afin d'insérer le titre.

## Kayn

Préserver :

- Kayn ;
- Rhaast ;
- ombre / mouvement.

Le titre du chapitre doit rester lisible sans recouvrir la faux.

## Xolaani

Éviter de montrer l'image trop tôt.

Son art doit apparaître :

- après sa première vraie révélation ;
- ou dans les annexes réservées au MJ.

# 7. Règle éditoriale

Les illustrations officielles ne doivent jamais remplacer les cartes ou les informations de jeu.

Priorité à la table :

1. carte ;
2. texte de scène ;
3. encadré tactique ;
4. illustration.

Une belle page qui rend une information difficile à trouver est une mauvaise page de JDR.
