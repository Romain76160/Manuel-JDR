# Légende graphique commune

- **jade** : Wuju / lieux spirituels ;
- **blanc** : circulations accessibles ;
- **ambre** : objectifs / éléments interactifs ;
- **rouge sombre** : menaces ou routes ennemies — version MJ uniquement ;
- **bleu** : eau / bassin / flux spirituel ;
- **pointillé** : passage secret ou route conditionnelle — version MJ uniquement.

Les cartes joueurs et MJ doivent conserver exactement la même géométrie afin de pouvoir être interchangées à la table.
