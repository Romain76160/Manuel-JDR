# Carte finale — Temple Wuju, niveau supérieur

> **Statut : spécification canonique de production.**
>
> Cette carte doit être générée comme **fond sans texte**, puis annotée séparément.

## Fonction

Le **niveau supérieur** est le Temple principal et comprend aussi l'entrée / vestibule.

Scènes principales :
- duel Yi / Kayn ;
- traversée des PJ ;
- défense du bassin ;
- circulation entre le vestibule et le niveau intermédiaire.

## Architecture obligatoire

La carte représente un **grand espace intérieur creusé dans la montagne**.

Elle doit contenir :

1. **Entrée / vestibule**
   - situé en partie haute de la carte ;
   - large, monumental ;
   - comprend les râteliers d'armes et l'accès extérieur.

2. **Temple principal**
   - grande salle centrale de pierre ;
   - architecture Wuju / ionienne ;
   - colonnes ou piliers ;
   - plusieurs axes de circulation.

3. **Bassin spirituel**
   - au centre ou légèrement décalé ;
   - eau turquoise / jade ;
   - plusieurs margelles utilisables comme couvert bas ;
   - l'eau peut déborder vers des rigoles.

4. **Arbre Wuju**
   - enraciné dans une ouverture naturelle ou un îlot intérieur ;
   - visible depuis la salle principale ;
   - élément spirituel majeur mais pas obstacle total.

5. **Dojo**
   - grande zone latérale ou attenante ;
   - sol plus dégagé ;
   - quelques râteliers d'armes d'entraînement ;
   - suffisamment ouvert pour une scène de combat.

6. **Grande cloche**
   - installée dans une alcôve ou plateforme intérieure ;
   - accessible sans passer à l'extérieur ;
   - peut être utilisée comme objectif pendant l'assaut.

7. **Escalier vers le niveau intermédiaire**
   - partie basse de la carte ;
   - connexion claire vers les dortoirs.

## Contraintes visuelles

- vue **top-down / battlemap** ;
- ratio proche de 4:3 ou carré ;
- aucune perspective isométrique ;
- aucun texte ;
- aucun numéro ;
- aucune flèche ;
- aucun personnage ;
- aucune silhouette ennemie ;
- aucune interface ;
- aucun faux kanji ;
- pas de grand ciel visible ;
- le lieu doit paraître **majoritairement souterrain**.

## Lumière

- lanternes chaudes ;
- quelques puits de lumière naturels ;
- reflets turquoise du bassin ;
- ambiance calme mais facilement convertible en scène nocturne.

## Terrain jouable

- plusieurs itinéraires autour du bassin ;
- au moins deux passages latéraux ;
- piliers utilisables comme couvert ;
- différences de niveau limitées ;
- pas de gouffres empêchant la circulation ;
- largeur suffisante pour un combat de 3 à 5 PJ.

## Style

- fantasy ionienne raffinée ;
- pierre claire, jade, bois sombre ;
- végétation limitée mais vivante ;
- brume très légère ;
- détails lisibles à l'impression.

## Rejet automatique

Rejeter si :
- la carte ressemble à un monastère extérieur ;
- on voit plusieurs bâtiments séparés à ciel ouvert ;
- le bassin devient un lac infranchissable ;
- un « cœur darkin » apparaît ;
- la corruption Darkin est déjà visible avant l'assaut ;
- la carte contient du texte généré.
