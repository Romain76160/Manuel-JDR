# Carte finale — Temple Wuju, niveau inférieur

> **Statut : spécification canonique de production.**
>
> Version joueurs : fond sans texte, sans ennemis, sans routes MJ et sans corruption Darkin visible par défaut.

## Fonction

Le **niveau inférieur** est le Reliquaire Wuju.

Scènes principales :
- arrivée du Transfuge ;
- protection ou découverte des Seigneurs des Darkin ;
- tentation de Jun par Xolaani ;
- confrontation finale directe contre Kayn.

## Architecture obligatoire

Le niveau est entièrement **creusé dans la montagne** et doit être plus solennel, ancien et resserré que les deux niveaux supérieurs.

### 1. Escalier vers le niveau intermédiaire
- en partie haute ;
- accès principal ;
- débouche sur une antichambre.

### 2. Antichambre
- espace de transition ;
- quelques piliers ;
- possibilités de couvert ;
- deux accès latéraux possibles.

### 3. Reliquaire central
- grande salle centrale ;
- plateforme circulaire ou octogonale ;
- autel / socle de reliques sobre ;
- aucun objet Darkin explicitement visible sur la version joueurs ;
- circulation possible tout autour.

### 4. Chambre des esprits
- espace adjacent ou derrière le reliquaire ;
- bassin ou conduit spirituel ;
- lumière jade / turquoise ;
- architecture plus ancienne.

### 5. Alcôves mémorielles
- niches, fourreaux, rubans, objets de mémoire ;
- réparties autour de la salle ;
- servent aussi de couverts partiels.

### 6. Colonnes et galeries
- plusieurs piliers massifs ;
- lignes de vue coupées ;
- deux passages latéraux ;
- espace suffisamment large pour un combat de boss niveau 3.

### 7. Accès vers les Grottes des esprits
- en partie basse ;
- escalier, tunnel ou ouverture rocheuse vers les Grottes des esprits ;
- lisible mais plus naturel que les escaliers supérieurs.

## Terrain jouable

- au moins trois axes tactiques autour du centre ;
- plusieurs couverts ;
- aucun gouffre central ;
- pas de cul-de-sac obligatoire ;
- distances compatibles avec 3 à 5 PJ ;
- centre ouvert pour Kayn, périphérie plus dense pour les objectifs.

## Contraintes visuelles

- battlemap strictement top-down ;
- aucun texte ;
- aucun numéro ;
- aucun personnage ;
- aucune route ou flèche ;
- aucun symbole Darkin évident ;
- aucune corruption rouge ;
- aucune prison de Xolaani ;
- aucune chambre inventée de type « Cœur oublié ».

## Palette

- pierre claire vieillie ;
- bois sombre limité ;
- jade / turquoise ;
- lanternes chaudes ;
- lumière spirituelle douce ;
- brume très légère ;
- ambiance sacrée et silencieuse.

## Rejet automatique

Rejeter si :
- la pièce est extérieure ;
- un cœur rouge ou une corruption Darkin domine le centre ;
- les Seigneurs des Darkin sont visibles comme objectif évident ;
- le niveau ressemble à une crypte gothique générique ;
- le passage vers -4 est absent ;
- du texte généré apparaît.
