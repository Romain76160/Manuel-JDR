# Carte finale — Temple Wuju, niveau intermédiaire

> **Statut : spécification canonique de production.**
>
> Carte destinée d'abord à la version **joueurs**, sans texte ni information secrète.

## Fonction

Le **niveau intermédiaire** est le quartier de vie des disciples et le point de départ des PJ pendant l'assaut.

Scènes principales :
- réveil et alarme ;
- évacuation des disciples ;
- premiers choix monter / tenir / descendre ;
- protection du cloître et de la bibliothèque.

## Architecture obligatoire

Le niveau doit être clairement **creusé dans la montagne** et relié verticalement aux niveaux supérieur et inférieur.

### 1. Escalier vers le niveau supérieur
- en partie haute ;
- large mais moins monumental que celui du temple principal ;
- débouche dans le cloître.

### 2. Cloître intérieur
- espace central calme ;
- galerie circulaire ou quadrangulaire ;
- petit jardin intérieur / bassin ;
- quelques arbres ou végétation spirituelle ;
- lumière naturelle limitée par puits de lumière.

### 3. Dortoirs des disciples
- plusieurs chambres simples de part et d'autre ;
- futons / lits bas / coffres ;
- mobilier sobre ;
- au moins deux ailes distinctes.

### 4. Bibliothèque / archives
- salle identifiable latéralement ;
- rayonnages, rouleaux, tables de lecture ;
- architecture cohérente avec le reste du temple ;
- espace utilisable comme zone défensive.

### 5. Zones communes
- petite salle de repas / thé ;
- espace de repos ;
- alcôves ou salles d'étude ;
- infirmerie légère possible.

### 6. Escalier vers le niveau inférieur
- en partie basse ;
- connexion claire vers le reliquaire.

## Jouabilité

- plusieurs couloirs de circulation ;
- deux ailes permettant de séparer le groupe ;
- lignes de vue partielles ;
- mobilier léger servant de couvert ;
- aucune zone totalement bloquante ;
- lisible pour 3 à 5 PJ.

## Contraintes visuelles

- vue strictement top-down ;
- aucune perspective isométrique ;
- aucun texte ;
- aucun numéro ;
- aucune flèche ;
- aucun personnage ;
- aucune présence Darkin ;
- aucun effet de combat ;
- intérieur rocheux majoritaire ;
- architecture ionienne / Wuju raffinée.

## Palette

- pierre claire ;
- bois sombre ;
- jade / vert ;
- lanternes chaudes ;
- petites touches florales ;
- bassin central turquoise discret.

## Rejet automatique

Rejeter si :
- le niveau ressemble à un village extérieur ;
- la bibliothèque prend tout l'espace ;
- le cloître devient une grande cour à ciel ouvert ;
- une corruption rouge/Darkin apparaît ;
- des annotations ou textes sont générés ;
- l'escalier vers le niveau inférieur n'est pas évident.
