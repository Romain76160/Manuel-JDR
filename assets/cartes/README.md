# Cartes du Manuel I — L'Héritage du Wuju

Ce dossier décrit les cartes retenues pour le Prologue et leur fonction dans le manuel.

Les fichiers image définitifs devront porter des noms stables afin que Homebrewery puisse les référencer sans casser les liens.

---

# 1. Temple Wuju — vue générale

**Statut : direction visuelle validée.**

Le Temple Wuju est désormais officiellement un **sanctuaire vertical creusé dans la montagne**.

La vue générale doit montrer clairement :

- entrée dans le flanc de la montagne ;
- niveau 0 — entrée / vestibule ;
- niveau -1 — temple principal / dojo ;
- niveau -2 — dortoirs / cloître ;
- niveau -3 — reliquaire ;
- niveau -4 — grottes des esprits.

Nom de fichier cible :

`temple-wuju-vue-generale.jpg`

Cette carte sert de **carte de référence MJ** pour le chapitre III.

---

# 2. Temple principal — niveau -1

**Statut : concept généré.**

Battlemap centrée sur :

- salle principale ;
- bassin / arbre intérieur ;
- dojo ;
- jardins intérieurs ;
- escaliers vers niveaux 0 et -2.

Usage : duel Yi–Kayn, traversée des PJ, combat contre les infiltrés.

Nom cible :

`temple-wuju-niveau-1.jpg`

---

# 3. Dortoirs / Cloître — niveau -2

**Statut : concept généré.**

Battlemap centrée sur :

- dortoirs des disciples ;
- cloître ;
- petit bassin central ;
- archives secondaires ;
- escaliers vers niveaux -1 et -3.

Usage : point de départ de l'assaut et évacuation des disciples.

Nom cible :

`temple-wuju-niveau-2-dortoirs.jpg`

---

# 4. Reliquaire — niveau -3

**Statut : concept généré.**

Battlemap centrée sur :

- chambre centrale du reliquaire ;
- alcôves latérales ;
- bassins et conduits spirituels ;
- entrée vers les grottes ;
- espace suffisant pour la confrontation finale.

Usage : combat contre le Transfuge puis combat final contre Kayn.

Nom cible :

`temple-wuju-niveau-3-reliquaire.jpg`

---

# 5. Grottes des esprits — niveau -4

**Statut : concept intégré à la carte générale, battlemap dédiée facultative.**

Usage :

- voie d'infiltration du Clan des Ombres ;
- possibilité de retraite ;
- interaction avec la Brume protectrice ;
- raccourci spirituel éventuel.

Nom cible :

`temple-wuju-niveau-4-grottes.jpg`

---

# 6. Chutes de Brume

**Statut : carte existante validée comme référence principale du chapitre II.**

Carte source historique : **Sanctuaire caché sous la cascade**.

Éléments importants :

- grande cascade ;
- bassin turquoise ;
- promontoire / épée d'Urong ;
- ruines sous ou derrière la chute ;
- sortie d'eau ;
- végétation et brume.

Nom cible :

`chutes-de-brume-sanctuaire.jpg`

La carte doit apparaître au centre du chapitre II, idéalement sur une page entière.

---

# 7. Chapitre I

Les cartes du chapitre I ne sont pas encore définitivement fixées.

Besoins probables :

- petite carte régionale Baie des Pins → Monastère Wuju ;
- Sanctuaire sous la Falaise ;
- éventuellement Shanmen pour l'Esprit Rancunier.

Éviter de produire une battlemap pour chaque scène. Le manuel doit conserver une impression d'aventure et non de succession de plateaux tactiques.

---

# Versions MJ et joueurs

Lorsque les cartes définitives seront exportées :

## Version MJ

Peut afficher :

- noms des salles ;
- routes d'infiltration ;
- passages secrets ;
- positions initiales ;
- numéros de référence.

## Version joueurs

Doit retirer :

- routes ennemies ;
- passages non découverts ;
- objectifs cachés ;
- emplacement secret des reliques si nécessaire.

Le terrain visible peut rester identique afin que les deux versions utilisent la même grille.
