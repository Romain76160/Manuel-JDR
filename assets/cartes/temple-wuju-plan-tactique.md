# Plan tactique — Temple Wuju

> **Statut : référence actuelle du Chapitre III — L'Assaut du Temple.**

Le Temple Wuju utilise désormais **trois battlemaps principales**, correspondant aux trois niveaux jouables du sanctuaire.

L'ancienne carte unique avec grande cour, toits et bâtiments extérieurs est abandonnée.

---

# Structure de l'assaut

## Niveau supérieur — Temple principal

Contient :

- entrée et vestibule ;
- râteliers d'armes ;
- bassin spirituel ;
- arbre Wuju ;
- dojo ;
- grande cloche.

### Fonction tactique

- infiltration supérieure ;
- récupération des armes ;
- révélation du magnétisme de Cassian ;
- duel Yi–Kayn.

Carte joueurs actuelle :

`assets/cartes/temple-wuju-niveau-1-joueurs.jpg`

---

## Niveau intermédiaire — Quartiers

Contient :

- dortoirs ;
- cloître intérieur ;
- bibliothèque ;
- espaces communs et de soin.

### Fonction tactique

Les PJ commencent ici.

Premier choix :

1. **monter** vers les armes et Yi ;
2. **tenir** les quartiers et protéger les disciples ;
3. **descendre** vers le Reliquaire.

Carte joueurs actuelle :

---

## Niveau inférieur — Reliquaire

Contient :

- salle centrale du reliquaire ;
- chambre des esprits ;
- alcôves mémorielles ;
- colonnes et couverts ;
- accès aux Grottes des esprits.

### Fonction tactique

- interception du Transfuge ;
- tentation de Jun par Xolaani ;
- réaction de Rhaast ;
- confrontation finale avec Kayn.

# Grottes des esprits

Les grottes ne forment pas une battlemap autonome obligatoire.

Elles représentent :

- la route d'infiltration inférieure ;
- une possible voie de retraite ;
- un objectif pouvant être fermé ou défendu ;
- une connexion naturelle vers l'extérieur.

---

# Pression simultanée

Le Clan des Ombres attaque :

- **par le niveau supérieur** ;
- **par les grottes**, directement vers le niveau inférieur.

Les PJ commencent au niveau intermédiaire.

Le MJ fait progresser l'autre front lorsque le groupe reste trop longtemps sur un niveau.

---

# Version joueurs

Aucune :

- route ennemie ;
- position de PNJ ;
- flèche ;
- information cachée ;
- relique secrète.

# Version MJ

Peut ajouter :

- route supérieure du Clan des Ombres ;
- route des grottes ;
- emplacement de Kayn ;
- emplacement du Transfuge ;
- position initiale de Jun et Cassian ;
- objectifs de scène.

Les versions joueurs et MJ utilisent **exactement le même fond**.

---

# Direction visuelle

Le Temple doit rester clairement Wuju / ionien :

- architecture intérieure creusée dans la montagne ;
- pierre claire ;
- bois sombre ;
- jade discret ;
- eau et végétation intégrées ;
- lanternes chaudes ;
- brume légère.

Aucune corruption Darkin ne doit être visible sur les fonds joueurs avant que le scénario ne la révèle.
