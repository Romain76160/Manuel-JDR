# Manuel JDR — La Seconde Guerre Darkin

Ce dépôt est la **source de référence** du projet de campagne JDR de Romain.

## Objectif

Conserver de façon persistante tout ce qui est validé pour la campagne afin de pouvoir reprendre le travail sans dépendre d'anciens chats :

- canon narratif ;
- décisions de conception ;
- manuscrit du manuel ;
- règles maison ;
- personnages et factions ;
- cartes, illustrations et aides de jeu ;
- tâches restantes.

## Projet actuel

### Manuel I — Prologue : *L'Héritage du Wuju*

Le Prologue est composé de **trois chapitres** :

1. **Les Épreuves du Wuju**
2. **Les Chutes de Brume**
3. **L'Assaut du Temple**

Le chapitre III constitue le **combat final du Prologue contre Kayn**.

## Fichiers importants

- `CANON.md` — faits officiellement établis dans la campagne ;
- `DECISIONS.md` — choix de conception et raisons ;
- `TODO.md` — travail restant ;
- `manuel/prologue/` — texte de travail du manuel ;
- `homebrewery/` — version destinée à la mise en page finale.

## Règle de travail

Lorsqu'une idée est définitivement validée, elle doit être inscrite dans `CANON.md` ou dans le chapitre concerné. Une idée encore discutée ne doit pas être traitée comme canon.
